# McdonaldsSurvey
Automatically opens up McDonalds Survey and fills out all required questions

---
# Why?
My brother eats at McDonalds way to much and if you fill out the survey, you get a Buy one Get One deal. Therefore instead of spending three minutes filling it out, the program fills it out within 10 seconds.
